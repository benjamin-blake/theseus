# Commercial licensing

Theseus is licensed under the Business Source License 1.1. Non-production use is permitted by
that licence at no cost. **Production use before the Change Date requires a commercial licence.**

See [`LICENSING.md`](LICENSING.md) for the licence boundary and [`LICENSE`](LICENSE) for the
operative terms, including the Additional Use Grant that defines what non-production use covers.

## Status

There is no commercial licence programme yet. No terms, no pricing and no offer are stated here,
and nothing on this page constitutes one.

This file exists so that `LICENSE`'s alternative-licensing pointer resolves to something honest
rather than to an empty placeholder. Shipping a licence that directs readers to a commercial
option while providing no way to ask about one is the defect it avoids.

## Enquiries

Open an issue at https://github.com/benjamin-blake/theseus/issues asking to be contacted about
commercial licensing. Do not include confidential details in a public issue -- say only that you
want to discuss licensing, and the maintainer will arrange a private channel.

A dedicated contact address is expected once `theseus.support` is live; this page will name it
directly at that point.

## What a commercial licence would cover

Recorded so the scope of any future discussion is not ambiguous:

- It would grant production use before the Change Date, which BUSL-1.1 otherwise reserves.
- It would not change the licence of any published version. Versions already published under
  BUSL-1.1 stay available under BUSL-1.1, and versions published under Apache-2.0 stay under
  Apache-2.0 -- see the forward-only rule in [`LICENSING.md`](LICENSING.md).
- It would not affect the Change Date. On 2030-08-15 each BUSL-1.1 version converts to Apache-2.0
  regardless, and a commercial licence cannot postpone that.
